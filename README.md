📱 MindLock
🚀 Features

Tracks total focus time and helps users understand their phone usage patterns.

Logs the purpose behind each phone unlock for better self-awareness.

Provides a simple reward system to encourage mindful usage.

Designed with a clean and minimal UI for a positive, non-judgmental experience.

📲 How to Use (Android)

Install and open the MindLock app on your Android device.

On every phone unlock, select the reason for unlocking.

Check the dashboard to view your focus time and unlock insights.

Stay consistent to unlock small rewards and build better focus habits.

⚠️ Prototype Status

MindLock is currently a working prototype built within a short hackathon timeframe.
Features, UI, and workflows may evolve as the project develops further.
